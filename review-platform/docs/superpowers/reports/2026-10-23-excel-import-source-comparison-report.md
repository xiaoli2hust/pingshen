## 1. 做了什么（用户视角）

导入 Excel 后，系统会把**原件本身**和**原件每个格子的样子**一起存下来。之后任何时候打开单据，都能看到左右两栏对照：

- **左栏是系统里的值**，每一行有三个值：
  - 原表里写的（原件值）；
  - 当次导入解析出的（导入值）；
  - 现在系统里存的（当前值）。

  另外，每一行都标一个状态：一致、已换算、有差异、已修改、已删除、在线补录或已剔除。
- **右栏是原表**，按原样显示，包括合并格、百分比、日期和两位小数的显示值。
- **两栏联动**：
  - 点左边一行，右边对应的原格会高亮；
  - 点右边一个格，左边会选中对应的行。
  - 顶部有公式栏，显示该格的完整原值。
- **筛选**："只看有差异"和"全部"之间可以切换。
- **下载原件**：凭登录身份下载。下载到的文件与上传时逐字节相同，中文文件名不会乱码。

对照覆盖四个导入入口：

- 预算表导入；
- 评审单导入（新建和历史存量都算）；
- 预算级附3交付明细；
- 商机级附3交付明细。

导入后的确认页能看到对照。之后再进入预算详情、评审详情或商机交付页，仍能看到当时那份原件的对照。

交付明细还多一块"合计核对"：实施和运维两个阶段各有人天和差旅五项，共 10 项。每一项都把原表合计行、导入值合计、当前值合计并排放在一起。

- 原表没有合计行时，显示"原件合计不可用"，不会当成 0。
- 这一块只用于披露差异，不会自动纠正任何数字。

## 2. 统一的"无预算数字行"口径

附3 里只有工作内容、没有任何人天或差旅数字的行，以前会被当成空明细行存进系统。现在四处用同一个判断（五个数字里至少一个大于 0 才保留）：

- Python 解析器；
- 服务端保存；
- 机器人草稿；
- 已存数据的开机清理。

被剔除的行不会悄悄消失：

- 对照里以"已剔除（原表有、系统未保留）"列出；
- 保存接口会返回剔除了几行；
- 如果一份附3全部是无数字行，导入直接报错并说明行数。
