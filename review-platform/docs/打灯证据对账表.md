# 打灯证据对账表

日期：2026-10-21。唯一映射来源为 `server.js` 的 `IND_EVIDENCE`；前端读取 `/api/meta/fields`，不另存指标与字段映射。

## 来源与边界

- **A 类·系统已算**：展示现有规则引擎输出的定量结论、计算过程和需上会事项，不由大模型判灯。
- **B 类·表单已采**：展示本张评审单已经填报的事实，空值明确显示未填，不推断补值。
- **C 类·部门自有系统**：平台没有这些依据、不负责采集或对接；部门按查询锚点在自己的系统中核验。
- 每项均提供商机代码、项目名称、客户、合同金额、申请人与申请时间六个基础锚点；本类型有登记字段时，追加签约路径、业务线和营销区域。变更单的合同金额优先显示变更后金额，缺失时显示原金额。
- 表内 A 类重点项仅用于突出显示；弹窗仍展示本类型全部已算定量项。缺失覆盖只作披露，不参与灯色、提交、锁定或结论权限。

## 统计与原说明书更正

共 19 项：纯 C 类 **9 项**、B+C **5 项**、纯 B 类 **5 项**；需要部门自有系统依据的合计 **14 项**。原说明书的 8/5/6 与 13 项统计和逐项表不一致，实施以逐项表为准。

售前立项规则没有“测绘类分包占比”定量项，因此售前的合同交付物任务不虚构该 A 类计算。未登记指标保守显示部门自有系统声明，不把空证据当作无风险。
