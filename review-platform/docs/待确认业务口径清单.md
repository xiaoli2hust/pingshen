## 历史与在线轨道的测试边界

历史补录 API 的合法结果是历史已归档评审，不能制造“历史单仍在前置评审中”的状态。在线评审必须经交付确认、预算锁定、申请人提交、真实部门打灯、结论确认及归档验证。

同一记录在线/历史来源互改没有已授权接口。相关回归采用真实历史导入与真实在线链的配对比较；原 CH-11b 历史 reviewing 状态与同记录 era 翻转的覆盖缺口必须在套件摘要及最终报告显式披露，不计作通过，也不以 SQL 恢复该覆盖。
